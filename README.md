# TaskFlow AI Concierge Agent

An AI-powered concierge agent that answers product questions using Retrieval-Augmented Generation (RAG), and can autonomously book demos and create support tickets. Built with LangChain, ChromaDB, HuggingFace embeddings, and Streamlit.

**Live app:** https://taskflow-ai-concierge-agent-cwdwptnmlehgmxchgekiiu.streamlit.app/

## Try it
- "What is Notion Agent?"
- "What are Notion's pricing plans?"
- "Book me a demo for tomorrow at 3pm"
- "Create a ticket - my workspace won't sync"

## Tech
RAG retrieval with relevance filtering, intent-based tool routing (BookDemo, CreateTicket, status checks), and conversation memory.
